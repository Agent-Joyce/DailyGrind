# Illustrated town assets

Generated with the built-in image-generation tool using the user-supplied reference image as a style reference. The final source atlas is buildings-source.png. The sixteen WebP files are cell extracts, resized without changing their aspect ratios for game use. Copies are embedded in index.html so the game remains standalone.

Order: employment office, school, bank, supermarket; fast food, restaurant, electronics, clothes; apartment, hospital, factory, thrift; community centre, bungalow, gym, park.

## Initial prompt

Create one production game sprite atlas with sixteen separate isometric neighbourhood buildings, four columns and four rows. Use the reference only for style: warm, inviting illustrated life-simulation game. Simplify broad shapes and windows, with soft painterly 3D shading and clean silhouettes. Keep each building isolated on transparent alpha, with consistent camera and scale, no text or numbers. Use warm cream/brick exteriors, teal details and leafy muted greens. Subjects in the exact order above. Do not reproduce the portrait strip or room interiors.

## Final refinement prompt

Refine the atlas, preserving all sixteen subjects and their row-major order. Make each illustration simpler: no tiny leaves, baskets or carts; just the building, one or two rounded trees and a plain small base. Use soft polished isometric 3D shading, broad shapes and warm cream/brick/teal colours. Clean transparent silhouettes without stray pixels or debris. Arrange sixteen equal cells with generous transparent margins and no overlapping buildings, grid lines, text, labels or numbers. Preserve recognisable map-ready building identities. This is a game sprite sheet rather than a concept poster.

The existing embedded portrait and interior illustrations remain in use. Portrait presentation now supports click/keyboard previews and automatic character moments; no new character identities were generated.
